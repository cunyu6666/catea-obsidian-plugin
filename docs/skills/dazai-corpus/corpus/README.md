# corpus/

用户自建目录。本仓库不提供任何文本内容，原因见上级 `SKILL.md` 的版权说明。

按需要的文件名建立即可，未建立的文件 agent 读不到，会降级为裸规则输出并明确告知。

| 文件名 | 装什么 |
|--------|--------|
| `confession.md` | 自白体节选 |
| `satire.md` | 讥刺、应酬文节选 |
| `decay.md` | 长句缠绕的段落 |
| `women.md` | 女性视角、口语滑进书面的段落 |
| `fragment.md` | 札记、断片 |

每个文件的格式：

```
# <篇名>（<年份>）
节选位置：<开头句 → 结尾句>
校准点：<这一篇主要学什么，一句话>

<正文节选>
```

单文件建议 1–3 KB。上限 48 KB，超了 agent 读取会失败。
