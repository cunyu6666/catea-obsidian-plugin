# README artwork

Three 1600 × 900 PNG exports introduce Catea at the top of the repository README.
All marketing copy is English, and the brand mark is editable text: `@CATEA`.

- [Editable Catea posters](https://www.figma.com/design/xrQ8iRV2gqTesSMNeJeWkU/RedNote?node-id=192-84)
- [Source template: Opuerow duotone editorial](https://www.figma.com/design/xrQ8iRV2gqTesSMNeJeWkU/RedNote?node-id=44-95)

| Asset | Figma node | Subject |
| --- | --- | --- |
| `catea-elegant-workspace.png` | `192:85` | Paper workspace and sidebar agent |
| `catea-agent-workflow.png` | `192:95` | Notes, research, and writing |
| `catea-your-knowledge.png` | `192:118` | Memory, model choice, and local storage |

The designs adapt the supplied template's Inter typography, bound Black/Lavender/Orange/White palette, and newly generated Catea-related halftone artwork. Text and layout remain editable in Figma. The original templates and LLMystery branding are unchanged; the Catea copies use only `@CATEA`.

The lavender artwork depicts a cat beside an open notebook with connected note cards; the orange artwork turns scattered research cards into a finished notebook. Both were generated with the built-in imagegen tool, replacing the unrelated horse and portrait from the original template. Original generated assets and exact prompts are recorded in [image-prompts.md](./image-prompts.md).

These are editorial promotional illustrations, not application screenshots. Export each named frame as PNG at its configured 1× scale to update the matching asset. Keep the filenames stable so README links continue to work.
