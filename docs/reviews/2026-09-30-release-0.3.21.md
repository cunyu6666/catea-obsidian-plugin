# Review of the pending 0.3.21 changes

Scope: the previously uncommitted host, agent, integration, settings, UI,
regression and documentation changes, including the existing BYOK vendor work.
The reviewed feature snapshot is `6f29262`; integration of the published
marketplace fixes is `255116e`.

## Findings resolved

- P1: `skill_create` could follow an existing `SKILL.md` symlink outside its
  package. Entry and resource targets now pass confinement checks before writes.
  Reserved case aliases and ancestor/descendant resource collisions are rejected.
  Complete packages are staged before replacement and competing package writes
  are serialized. Approval includes resource contents, not just filenames.
- P1: the local branch still carried the failed full Node declaration snapshots.
  Merge the published 0.3.20 runtime contracts and structural compatibility gate
  to avoid reintroducing marketplace failures. Add only the exclusive-write flag
  used by the new media tools to the minimal contract.
- P2: bundled skill adaptations did not include full upstream licenses in the
  three assets downloaded by Obsidian. Include both license texts in the bundle
  header as well as standalone distribution files.
- P2: the vendor asset tracking gate checked filesystem presence rather than Git
  tracking. Check the actual tracked-file inventory.

No remaining code-level release blockers were identified in this review.
This is not a claim that all possible defects have been excluded.

## Verification

The merged implementation passed `npm run check`: 414 tests, 60 behavior
regressions, formatting, typecheck, official lint, dependency-poor marketplace
analysis, and build. The built JavaScript measured 4,505,363 bytes, below 5 MB.
The regression additions cover symlink escape, reserved aliases, conflicting
resources, concurrent creation and replacement cleanup. Existing media tests
cover key isolation, binary fallback, task cancellation/resumption and saved
playback paths. Build and governance tests were rerun after the version bump.

Earlier direct provider checks produced valid image, MP4 and MP3 artifacts;
these are local test outputs and are not release assets. No test API key is
included in committed source.

## Release status and limits

Version 0.3.21 and its release notes are prepared locally. No push or release was
performed as part of this review. A separate test vault was prepared at
`/tmp/catea-release-smoke-20260930`, but host UI verification was stopped when
computer-use reported concurrent user activity in Obsidian. The test vault build
is therefore not evidence of a successful plugin load. Complete the live smoke
test required by CONTRIBUTING.md before publishing. The remote marketplace must
also scan the newly published release; the local gate cannot establish its result.
