# Catea HTML / SVG 编辑器预览

在 Obsidian 实时预览或阅读模式打开。实时预览中将光标移出代码块后显示预览；使用 Obsidian 原生的编辑代码块按钮修改内容。纯源码模式不改变。预览禁止脚本和外部资源请求，图片需使用 data URL。可拖动预览右下角调整高度。

```html
<div style="padding:28px;border-radius:16px;background:#edf3ef;border:1px solid #d5e2d9">
  <h2 style="color:#205843">Hello, Catea Paper</h2>
  <p>这是笔记正文中的 HTML 预览。</p>
</div>
```

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 160">
  <rect x="10" y="10" width="380" height="140" rx="20" fill="#edf3ef"/>
  <circle cx="80" cy="80" r="36" fill="#205843"/>
  <text x="140" y="87" font-size="24" fill="#205843">Catea SVG</text>
</svg>
```
